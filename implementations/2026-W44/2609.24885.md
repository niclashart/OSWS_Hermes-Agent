# The Copy Ceiling: An Input-Exposure Control for Ontology-Grounded Generation over Curated Corpora

## Why — evidence

Introduces a copy baseline and exposure accounting for RAG evaluation. Score 9/10.

> "Across ten models, grounding raised target-name recall from 0.265 unaided to about 0.92. A copy
> baseline, the recall a verbatim copy of the shown context already achieves, scores 0.964, and
> every model sits 0.022 to 0.067 below it." (Abstract)

Interpretation: a recall score alone can't distinguish retrieval+reasoning from verbatim copying.
RAG-NIMBF reports nDCG@k / Hit@k / answer metrics but no baseline that bounds what copying alone
achieves — the copy ceiling closes that interpretability gap cheaply.
https://arxiv.org/abs/2609.24885

## Proposal: RAG-NIMBF

### Design

Add **copy-ceiling metrics** to `benchmark/custom_metrics.py`: for each sample, compute the recall
of the ground-truth answer achievable by verbatim copying of the shown contexts, and compare the
model's answer-level score against it. Two new per-sample metrics:

- `copy_ceiling` — token-overlap F1 between a verbatim extractive "answer" built from the contexts
  (the oracle copy: the best contiguous n-gram span of the contexts vs. the ground truth) and the
  ground truth. This is the ceiling the paper describes.
- `answer_vs_copy_gap` — `copy_ceiling - rouge_l(answer, ground_truth)`: a negative gap means the
  model beat copying (evidence of synthesis); a large positive gap means reported scores may be
  copying artifacts.

Where it plugs in: inside `compute_custom_metrics()` per-sample loop (after the NLG block), reusing
`_tokenize()` and the existing `rouge_l()`. No config change strictly required — the metrics ride
along `custom_metrics_enabled`. Optional kill-switch: `custom_metrics_copy_ceiling: bool = True`
in `config.py` + `CUSTOM_METRICS_COPY_CEILING` env.

New pure function (add in the NLG-metrics section):

```python
def copy_ceiling(ground_truth: str, contexts: list[str]) -> float:
    """F1 between the ground truth and a verbatim copy of the contexts.

    Draft generated by RAG Radar — untested, review before applying.

    The copy baseline (arXiv:2609.24885): how much of the ground truth is
    recoverable by verbatim copying of the shown context alone. Computed as
    the best sentence-level ROUGE-L over sliding windows of the concatenated
    contexts (a copy 'answer' can only reuse contiguous context text).
    """
    joined = "\n".join(contexts)
    sentences = [s.strip() for s in joined.split("\n") if s.strip()]
    best = 0.0
    window: list[str] = []
    for sentence in sentences:
        window.append(sentence)
        # Window grows to roughly ground-truth length; a longer copy cannot
        # improve F1 against the reference.
        while sum(len(s) for s in window) > max(len(ground_truth) * 2, 50):
            window.pop(0)
        best = max(best, rouge_l(" ".join(window), ground_truth))
    return best
```

No experiment config change needed — metrics appear automatically under

### Tests

`tests/test_copy_ceiling.py`:

```python
"""Tests for the copy-ceiling metric (arXiv:2609.24885) — draft."""

from benchmark.custom_metrics import copy_ceiling, _tokenize


def test_verbatim_context_scores_high():
    gt = "Photosynthesis converts light energy into chemical energy."
    ctx = ["Intro paragraph about leaves.",
           "Photosynthesis converts light energy into chemical energy.",
           "Another unrelated paragraph."]
    assert copy_ceiling(gt, ctx) > 0.9


def test_unrelated_context_scores_low():
    gt = "Photosynthesis converts light energy into chemical energy."
    ctx = ["The stock market fell sharply on Tuesday."]
    assert copy_ceiling(gt, ctx) < 0.3


def test_partial_context_gives_partial_ceiling():
    gt = "Photosynthesis converts light energy into chemical energy in chloroplasts."
    ctx = ["Photosynthesis converts light energy into chemical energy."]
    score = copy_ceiling(gt, ctx)
    assert 0.3 < score < 0.95


def test_empty_contexts_returns_zero():
    assert copy_ceiling("any ground truth", []) == 0.0
```

### Effort & risks

**S** — one pure function + ~10 lines in the per-sample loop + tests. Risks: the sliding-window
heuristic is an approximation of the paper's oracle copy (they compute exact target-name recall on
an ontology-grounded corpus); for NIMBF's purposes (a lower bound that contextualises answer
scores) the ROUGE-L window version is sufficient but should be documented as such in the metric
docstring. Open question: whether `answer_vs_copy_gap` should also be reported in
`benchmark/reporting/` charts (follow-up).

## Blueprint verdict — not proposed

`partial` but not proposed: evaluation in the Blueprint is a per-request LLM check
(`chain/check_answers_llm.py`); a corpus-level copy ceiling belongs in the benchmarking framework,
not the production chain. Adding it there would duplicate NIMBF's evaluation stack.
