(Llama-3.1-8B-Instruct), prompt and judge protocol; 19,484 synthetic questions, open code + data
(CC BY 4.0). Score 10/10.

> "All six pipelines share the same generator (Meta-Llama/Llama-3.1-8B-Instruct), prompt, and
> evaluation protocol; the five single-vector pipelines additionally share SPECTER2 embeddings and

> 2024-2025." (Abstract)

Headline finding: cross-encoder reranking and ColBERTv2 late interaction beat plain dense top-k,
query rephrasing and agentic tool-call retrieval under identical conditions.

## Proposal: RAG-NIMBF

### Design

Add a **ColBERT-style late-interaction reranker** as a new reranker provider, reusing the existing
`Reranker` protocol — no adapter, matrix or config changes needed. The paper's reranking finding is
already benchmarkable via `matrix.reranker_models`; this closes the late-interaction gap so the
paper's two headline strategies (cross-encoder vs late interaction) become one grid axis.

- Where: `benchmark/reranker_colbert.py` (NEW), registered in the `get_reranker` factory
  (`benchmark/reranker.py`, MODIFY) under provider prefix `huggingface-colbert:<hf-id>`.
- Data flow: internal adapter `_rerank()` → `get_reranker("huggingface-colbert:colbert-ir/colbertv2.0")`
  → `ColBERTMaxSimReranker.rerank(query, docs, top_k)` → token-level embeddings → MaxSim per doc →
  sorted list of Documents, same contract as `CrossEncoderReranker`.
- Defaults: `max_query_tokens=32`, `max_doc_tokens=300`, CPU/cuda auto-select; score stored on
  `doc.metadata["late_interaction_score"]` for analysis.
- Config key: unchanged — `matrix.reranker_models` accepts any string (see
  `orchestration/matrix.py:255-258`); `config.py` run-label code (`rerank-{model}`) works as-is.
- RRF fusion of query variants is NOT included (needs a new query-transformation axis + result
  fusion in `retrieve()`; separate proposal).

#### NEW `benchmark/reranker_colbert.py`

```python
"""ColBERT-style late-interaction reranker.

Draft generated by RAG Radar — untested, review before applying.

Implements the existing ``Reranker`` protocol from ``benchmark.reranker`` using
token-level (late-interaction) scoring: every query token attends to its best
matching document token (MaxSim), and document scores are the sum of per-query-
token maxima. Based on the finding that late interaction rivals or beats
cross-encoder reranking (arXiv:2609.38473).

Requires the ``transformers`` extra already used by the embedding stack.
Model ids are ColBERT checkpoints, e.g. ``colbert-ir/colbertv2.0`` (MIT).
"""
from __future__ import annotations

import mlflow

from langchain_core.documents import Document

from benchmark.tracing import observe


class ColBERTMaxSimReranker:
    """Late-interaction reranker using MaxSim over token embeddings.

    Parameters
    ----------
    model_name:
        HuggingFace ColBERT checkpoint, e.g. ``colbert-ir/colbertv2.0``.
    device:
        ``"cpu"`` or ``"cuda"``; auto-detected when ``None``.
    max_query_tokens / max_doc_tokens:
        Truncation limits (ColBERT models use 32-token queries by convention).
    """

    def __init__(
        self,
        model_name: str,
        device: str | None = None,
        max_query_tokens: int = 32,
        max_doc_tokens: int = 300,
    ) -> None:
        import torch
        from transformers import AutoModel, AutoTokenizer

        self._torch = torch
        self.tokenizer = AutoTokenizer.from_pretrained(model_name)
        self.model = AutoModel.from_pretrained(model_name)
        self.model.eval()
        if device is None:
            device = "cuda" if torch.cuda.is_available() else "cpu"
        self.device = device
        self.model.to(device)
        self.max_query_tokens = max_query_tokens
        self.max_doc_tokens = max_doc_tokens

    def _token_embeddings(self, texts: list[str], max_tokens: int):
        """Return (n, n_tokens, dim) L2-normalized embeddings + attention mask."""
        torch = self._torch
        enc = self.tokenizer(
            texts,
            padding=True,
            truncation=True,
            max_length=max_tokens,
            return_tensors="pt",
        ).to(self.device)
        with torch.no_grad():
            out = self.model(**enc).last_hidden_state  # (n, T, D)
        mask = enc["attention_mask"].unsqueeze(-1).bool()  # (n, T, 1)
        emb = torch.nn.functional.normalize(
            out * enc["attention_mask"].unsqueeze(-1), p=2, dim=-1
        )
        return emb, mask

    @mlflow.trace(name="rerank_colbert", span_type="func")
    @observe(name="rerank")
    def rerank(
        self, query: str, documents: list[Document], top_k: int
    ) -> list[Document]:
        """Score documents via late-interaction MaxSim and return the top-k.

        Returns at most ``top_k`` documents, ordered by descending score.
        """
        if not documents:
            return []

        q_emb, q_mask = self._token_embeddings([query], self.max_query_tokens)
        d_emb, d_mask = self._token_embeddings(
            [d.page_content for d in documents], self.max_doc_tokens
        )

        # sim[q_tok, d_tok] = dot product; mask padded tokens with -inf.
        sim = torch.einsum("qtd,ntd->qnt", q_emb, d_emb)  # (1, Q, N, T_doc)
        doc_key_mask = d_mask.squeeze(0).unsqueeze(0)  # (1, 1, T_doc)
        sim = sim.masked_fill(~doc_key_mask, float("-inf"))
        query_token_mask = q_mask.squeeze(0).squeeze(-1).unsqueeze(-1)  # (1, Q, 1)
        sim = sim.masked_fill(~query_token_mask, float("-inf"))

        # MaxSim: best document token per query token, then sum over query tokens.
        max_sim = sim.max(dim=-1).values  # (1, Q, N)
        query_valid = query_token_mask.squeeze(-1).squeeze(0)  # (Q, 1)
        max_sim = torch.where(
            query_valid.unsqueeze(-1), max_sim, torch.zeros_like(max_sim)
        )
        scores = max_sim.sum(dim=1).squeeze(0).tolist()  # (N,)

        ranked = sorted(
            zip(scores, documents), key=lambda x: x[0], reverse=True
        )
        out = []
        for score, doc in ranked[:top_k]:
            doc.metadata["late_interaction_score"] = float(score)
            out.append(doc)
        return out
```

### Design

Add an optional **cross-encoder reranking stage** between query refinement and generation. The
refined question currently goes straight into the Chroma retriever
(`chain/handle_llms.py:90-100`); the paper shows cross-encoder reranking is the single largest
quality lever under a fixed generator.

- Where: NEW `chain/reranker.py` defining `RerankingRetriever`, a LangChain `BaseRetriever` that
  wraps the existing retriever and re-sorts with a `sentence_transformers.CrossEncoder`.
- Wiring: `chain/handle_llms.py` wraps the retriever after `create_retriever(...)` when
  `RERANKER_ENABLED=true` — default off, so behavior is unchanged unless enabled.
- Data flow: `refine_query` → base retriever (role-filtered, as today) → fetch
  `RERANKER_CANDIDATES` docs → cross-encoder scores → top `retriever_top_k()` → existing chain.
- Defaults: model `cross-encoder/ms-marco-MiniLM-L-6-v2` (Apache-2.0), candidates 10, env-driven.

```python
"""
Draft generated by RAG Radar — untested, review before applying.

Cross-encoder reranking stage for the RAG chain.

Wraps the existing role-filtered retriever: fetches a larger candidate set,
re-scores every candidate against the query with a local cross-encoder and
returns only the top-k. Enabled via environment variables so behaviour is
unchanged by default:

    RERANKER_ENABLED=true
    RERANKER_MODEL=cross-encoder/ms-marco-MiniLM-L-6-v2
    RERANKER_CANDIDATES=10
"""
import os

from langchain_core.callbacks import CallbackManagerForRetrieverRun
from langchain_core.documents import Document
from langchain_core.retrievers import BaseRetriever

from retriever_top_k_shim import retriever_top_k  # noqa: F401  (see note below)

def _env_flag(name: str) -> bool:
    return os.getenv(name, "").strip().lower() in {"1", "true", "yes"}

def reranker_enabled() -> bool:
    return _env_flag("RERANKER_ENABLED")

def reranker_model() -> str:
    return os.getenv("RERANKER_MODEL", "cross-encoder/ms-marco-MiniLM-L-6-v2")

def reranker_candidates(default: int = 10) -> int:
    try:
        n = int(os.getenv("RERANKER_CANDIDATES", default))
    except (TypeError, ValueError):
        return default
    return n if n > 0 else default


class RerankingRetriever(BaseRetriever):
    """Retriever that re-sorts another retriever's results with a cross-encoder."""

    base_retriever: object
    cross_encoder: object
    top_k: int = 5

    @classmethod
    def create(cls, base_retriever, top_k: int) -> "RerankingRetriever":
        from sentence_transformers import CrossEncoder

        return cls(
            base_retriever=base_retriever,
            cross_encoder=CrossEncoder(reranker_model()),
            top_k=top_k,
        )

    def _get_relevant_documents(
        self, query: str, *, run_manager: CallbackManagerForRetrieverRun
    ) -> list[Document]:
        candidates = self.base_retriever.invoke(query) or []
        if not candidates:
            return []
        pairs = [(query, doc.page_content) for doc in candidates]
        scores = self.cross_encoder.predict(pairs)
        ranked = sorted(
            zip(scores, candidates), key=lambda x: x[0], reverse=True
        )
        return [doc for _, doc in ranked[: self.top_k]]


def maybe_wrap_reranker(retriever, top_k: int = 5):
    """Wrap *retriever* with cross-encoder reranking when RERANKER_ENABLED."""
    if retriever is None or not reranker_enabled():
        return retriever
    if reranker_candidates() <= top_k:
        # Nothing to rerank: candidate set would be truncated anyway.
        return retriever
    from langchain_core.documents import Document  # noqa: F401

    return RerankingRetriever.create(base_retriever=retriever, top_k=top_k)
```
