# Better Retrievers, Worse Labels: How Incomplete Relevance Judgments Distort Abstention Evaluation in Conversational RAG

Draft generated by RAG Radar — untested, review before applying.

## Why — evidence
> "The stronger the retriever, the larger the share of no-gold contexts that still contain the answer (28% to 72%) and the lower the shortcut's precision (.68 to .10; .70 to .21 under the audit)." (Abstract / Sec. 4)

> "Qwen3-4B answers 62–67% of these false misses correctly" (Abstract)

NIMBF scores refusal/abstention relative to gold-document presence; with strong retrievers this mislabels answerable cases as unanswerable. Directly affects `abstain_strict` prompt arms and refusal metrics.

## Proposal: RAG-NIMBF

### Design
Add a content-based sufficiency/answerability audit: after generation, a small local judge model (`get_chat_model`) reads the question + retrieved contexts and labels whether the contexts contain the answer (`context_sufficient`). Store `sufficiency_label` per sample. New metrics computed only where labels exist: `abstention_precision` (of predicted refusals, how many truly lack the answer in context), `false_miss_rate` (answerable-but-refused), and AUROC of refusal against sufficiency. Gated by config flag `abstention_audit_enabled` (default off, so existing runs are unchanged).

Data flow: `evaluation` stage → judge call → labels appended to per-sample records → `custom_metrics`-style aggregation in `reporting`.

### Files

#### NEW `benchmark/abstention_audit.py`
```python
"""Draft generated by RAG Radar — untested, review before applying.

Content-based sufficiency audit for abstention evaluation.
Instead of inferring 'unanswerable' from missing gold documents, a local
judge reads question + retrieved contexts and labels sufficiency.
"""
from __future__ import annotations

import os
from typing import Callable, Sequence

_JUDGE_PROMPT = (
    "Question: {q}\n\nContexts:\n{ctx}\n\n"
    "Do the contexts contain the information needed to answer the question? "
    "Answer with exactly YES or NO."
)


def label_sufficiency(
    questions: Sequence[str],
    contexts: Sequence[Sequence[str]],
    chat_model,
) -> list[bool]:
    """True = contexts are sufficient to answer."""
    labels = []
    for q, ctx in zip(questions, contexts):
        ctx_block = "\n---\n".join(c[:800] for c in ctx) or "(empty)"
        out = chat_model.invoke(_JUDGE_PROMPT.format(q=q, ctx=ctx_block))
        text = str(getattr(out, "content", out)).strip().upper()
        labels.append(text.startswith("YES"))
    return labels


def abstention_metrics(
    sufficiency: Sequence[bool],
    answers: Sequence[str],
    is_refusal: Callable[[str], bool],
) -> dict:
    """Precision of refusals + false-miss rate against sufficiency labels."""
    n_ref = sum(1 for a in answers if is_refusal(a))
    tp = sum(1 for s, a in zip(sufficiency, answers) if is_refusal(a) and not s)
    fp = n_ref - tp
    answerable = sum(1 for s in sufficiency if s)
    false_miss = sum(
        1 for s, a in zip(sufficiency, answers) if s and is_refusal(a)
    )
    return {
        "abstention_precision": tp / n_ref if n_ref else None,
        "refusals": n_ref,
        "false_misses": false_miss,
        "false_miss_rate": false_miss / answerable if answerable else None,
        "sufficient_share": (
            sum(1 for s in sufficiency if s) / len(sufficiency) if sufficiency else None
        ),
    }
```

### Tests — NEW `tests/test_abstention_audit.py`
```python
"""Draft generated by RAG Radar — untested, review before applying."""
from unittest.mock import MagicMock

from benchmark.abstention_audit import label_sufficiency, abstention_metrics


def _judge(reply):
    m = MagicMock()
    m.invoke.return_value = MagicMock(content=reply)
    return m


def test_label_yes_no():
    j = _judge("YES")
    assert label_sufficiency(["q"], [["c"]], j) == [True]
    j2 = _judge("NO")
    assert label_sufficiency(["q"], [["c"]], j2) == [False]


def test_metrics_counts():
    suff = [True, False, False, True]
    answers = ["answer", "I cannot answer.", "I cannot answer.", "refused: insufficient"]
    m = abstention_metrics(suff, answers, lambda a: "cannot" in a or "insufficient" in a)
    assert m["refusals"] == 3
    assert m["false_misses"] == 1
    assert abs(m["abstention_precision"] - 2 / 3) < 1e-9
    assert m["false_miss_rate"] == 0.5


def test_no_refusals_gives_none_precision():
    m = abstention_metrics([True], ["ans"], lambda a: False)
    assert m["abstention_precision"] is None
```

### Effort & risks
S/M. Risks: judge quality — the paper itself found blind-audited LLM judges imperfect (.21 precision under the audit for the shortcut); mitigate with a 3-judge majority as follow-up. Cost: one small-model call per sample, fine on Ollama. The paper's headline (answerability AUROC up to .19 too low) should be reproduced on one NIMBF dataset before claiming the fix.
