# OpticalRAG: Pixel-Space Compression for Token-Efficient Retrieval-Augmented Generation

Draft generated by RAG Radar — untested, review before applying.

## Why — evidence
> "On LongBench-v2, BAMBOO, and LooGLE-v2, OpticalRAG achieves the best compression-aware accuracy (CAP) on all three benchmarks while injecting only $16$ tokens, and improves the closed-book Qwen2.5-7B-Instruct backbone by $5.17$ points on LongBench-v2." (Abstract)

Feasible: frozen DeepSeek-OCR DeepEncoder (~100 visual tokens/page) + a ~30.7M-parameter cross-attention compressor; code MIT, weights released (rubric C 2). RAG-NIMBF has no context-compression axis at all — the paper defines a new benchmarkable stage between retrieval and generation with a token-budget trade-off that the framework currently cannot express.

## Proposal: RAG-NIMBF

### Design — where it plugs in
New optional stage between retrieval and generation, expressed as a config axis so it enters the matrix like any other:

- New config fields (one axis):
  - `context_compression: str = "none"` — values `none` | `opticalrag`.
  - `context_compression_budget: int = 16` — max compressed prefix tokens per sample.
- New module `benchmark/context_compression.py` with a `ContextCompressor` protocol and an `OpticalRagCompressor` implementation: renders each retrieved chunk's source page (chunk metadata `source`/`page`, falling back to rendering the chunk text itself) to an image, encodes it with the frozen DeepSeek-OCR DeepEncoder, retrieves visual tokens via the released Encoder-Bridged projection, and distills them into `context_compression_budget` query-conditioned prefix tokens with the released compressor checkpoint. Optional dependency (`opticalrag` extra); when the package or checkpoint is missing, `get_compressor` raises a clear `ValueError` at adapter build time, not mid-run.
- `InternalRagAdapter.generate()` compresses only when `config.context_compression != "none"`; compressed prefixes are passed to `generate_answer` as the context strings, and the compressor reports the token count it injected, which is logged into `AdapterGenerationResult.metadata`-style tracing via the existing `observe` decorator — so the compression-vs-accuracy trade-off (the paper's CAP metric) becomes plottable from existing run records.
- Defaults keep every existing run byte-identical (`context_compression="none"`), and the cache key (`target_cache_key`) is unchanged because compression is query-time only.

Data flow: `retrieve()` → rerank → `compress(config, contexts, sources)` → `generate_answer(contexts=compressed_prefixes)` → metrics include `compressed_tokens`.

```python
"""Draft generated by RAG Radar — untested, review before applying.

Context compression stage (OpticalRAG-style): compress retrieved context
into a small number of query-conditioned prefix tokens before generation.
"""
from __future__ import annotations

from typing import Any, Protocol


class ContextCompressor(Protocol):
    """Compress retrieved contexts before generation."""

    def compress(
        self, question: str, contexts: list[str], sources: list[dict[str, Any]] | None = None
    ) -> tuple[list[str], int]:
        """Return (compressed_contexts, injected_token_count)."""
        ...


class OpticalRagCompressor:
    """Pixel-space compressor: render pages, encode visually, distill to prefix tokens.

    Requires the optional ``opticalrag`` dependency and the released
    DeepEncoder + compressor checkpoints.
    """

    def __init__(self, budget: int = 16, encoder_id: str | None = None, device: str = "cuda") -> None:
        try:
            from opticalrag import OpticalRAGCompressor as _Impl  # optional extra
        except ImportError as exc:  # pragma: no cover - environment guard
            raise ValueError(
                "context_compression='opticalrag' requires the optional "
                "'opticalrag' package and model checkpoints"
            ) from exc
        self._impl = _Impl(budget=budget, encoder_id=encoder_id, device=device)
        self.budget = budget

    def compress(
        self, question: str, contexts: list[str], sources: list[dict[str, Any]] | None = None
    ) -> tuple[list[str], int]:
        if not contexts:
            return [], 0
        prefixes, n_tokens = self._impl.compress(question, contexts, sources or [{}] * len(contexts))
        return list(prefixes), int(n_tokens)


def get_compressor(model_string: str | None, budget: int = 16) -> ContextCompressor | None:
    """Factory mirroring benchmark.reranker.get_reranker."""
    if not model_string or model_string == "none":
        return None
    if model_string == "opticalrag":
        return OpticalRagCompressor(budget=budget)
    raise ValueError(
        f"Unsupported context compression '{model_string}'. Supported: 'none', 'opticalrag'."
    )
```

```python
"""Draft generated by RAG Radar — untested, review before applying."""
import pytest

from benchmark.context_compression import get_compressor


def test_none_returns_no_compressor():
    assert get_compressor(None) is None
    assert get_compressor("none") is None


def test_unknown_provider_raises():
    with pytest.raises(ValueError):
        get_compressor("bogus")


class _FakeCompressor:
    def compress(self, question, contexts, sources=None):
        return ["PFX"], 16


def test_opticalrag_factory(monkeypatch):
    import benchmark.context_compression as cc

    monkeypatch.setattr(cc, "OpticalRagCompressor", lambda budget=16, **kw: _FakeCompressor())
    comp = get_compressor("opticalrag", budget=16)
    ctx, n = comp.compress("q", ["a", "b"])
    assert ctx == ["PFX"] and n == 16


def test_internal_adapter_skips_compression_by_default():
    from types import SimpleNamespace
    from benchmark.adapters.internal import InternalRagAdapter

    cfg = SimpleNamespace(
        context_compression="none", context_compression_budget=16,
        retrieval_mode="direct", llm_answer_strip_mode="tags_only",
        llm_answer_value_fallback=True, prompt_template="concise", llm_model="x",
    )
    adapter = InternalRagAdapter(generator=lambda *a, **k: SimpleNamespace(
        answer="1", ttft_seconds=0, total_seconds=0, input_tokens=0,
        output_tokens=0, total_tokens=0, estimated_cost_usd=0,
        raw_content="1", raw_reasoning=None, answer_valid=True))
    res = adapter.generate(None, {"question": "q", "context": "c"}, cfg)
```

### Effort & risks
**M**. Risks: (1) `opticalrag` package/checkpoint API may differ from this sketch — adapter must be written against the released repo, not guessed; (2) rendering chunks without real page images degrades quality — require `corpus_parser`-produced Markdown with source paths, warn when metadata lacks `source`; (3) prefix-token contexts bypass text metrics assumptions in RAGAS — restrict compression arms to answer-accuracy + token-cost metrics initially. Open question: whether compressed prefixes should also feed retrieval metrics (they shouldn't — keep `retrieval_result` untouched, as in the diff).
