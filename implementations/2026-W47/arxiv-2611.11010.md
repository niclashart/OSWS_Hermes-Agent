# Lightfoot: Graph Retrieval-Augmented Generation with Exact, Model-Free Document Deletion

Draft generated by RAG Radar — untested, review before applying.

## Why — evidence
> "On the full 11,402-passage MuSiQue corpus we verify that, after deleting 10% of the documents, the graph is identical to a fresh index of the surviving documents." (Abstract)

> "Lightfoot builds the cheapest index on all three datasets, 26-31% below HippoRAG 2 and 3-6x below LightRAG and fast-graphrag." (Abstract)

> "Against HippoRAG 2 it is significantly better on MuSiQue retrieval (+2.8 points recall@5 and +4.3 recall@10 on a held-out split) and on HotpotQA answers (+7.7 points exact match), and significantly worse on 2WikiMultiHopQA (-3.9 recall@2, -8.4 F1)." (Abstract)

Two things are new for benchmarking, independent of graph RAG itself: (1) deletion correctness as a reproducible property test, and (2) index-build cost (LLM calls, time) as a first-class metric. The Blueprint's loader supports document deletion (per-source chunks removed from Chroma) but has no test that the resulting index equals a fresh index — exactly the invariant Lightfoot proves for its own index.

## Proposal: RAG-NIMBF

### Design
Bring Lightfoot's two benchmarkable ideas into RAG-NIMBF without adopting full graph RAG (which the fit check already tracks as a new axis):

1. **Index-cost metrics**: during `benchmark_stage: index` (and in the `prepare()` phase of `all`), record and report `index_llm_calls`, `index_seconds`, `index_chunks` alongside the existing `chunk_count` metadata. No new component — counters added to `PreparedTarget.metadata` and summed in reporting.
2. **Deletion-invariant property test as a dataset-independent stage**: new `deletion_check_enabled` flag (default off). When on, the runner after `prepare()` deletes a configurable fraction (`deletion_fraction`, default 0.1) of the corpus documents via the adapter, re-chunks the survivors, and compares against a freshly built index over the survivors using the existing `corpus_fingerprint` machinery plus per-chunk text comparison. Result recorded as a boolean metric `deletion_invariant_passed` — exactly Lightfoot's "identical to a fresh index" check, applied to the chunked corpus RAG-NIMBF actually benchmarks (full graph-level equality is out of scope until a graph axis exists).

This makes index cost and deletion behavior comparable across chunking strategies and vector-store backends — a new benchmarkable dimension at S effort, no benchmark runs triggered by this proposal itself.

"""Draft generated by RAG Radar — untested, review before applying.

Deletion-invariant check (Lightfoot-style): after deleting a fraction of
the corpus, the rebuilt index must be identical to a fresh index of the
surviving documents.
"""
from __future__ import annotations

import logging
import random
from typing import Any

logger = logging.getLogger(__name__)


def _group_by_source(chunks: list[Any]) -> dict[str, list[Any]]:
    grouped: dict[str, list[Any]] = {}
    for c in chunks:
        source = getattr(c, "metadata", {}).get("source", "unknown") if isinstance(getattr(c, "metadata", None), dict) else "unknown"
        grouped.setdefault(source, []).append(c)
    return grouped


def deletion_invariant_report(
    chunks: list[Any],
    rebuild_fn,
    deletion_fraction: float = 0.1,
    seed: int = 0,
) -> dict[str, Any]:
    """Delete ``deletion_fraction`` of documents, rebuild, compare with fresh.

    ``rebuild_fn(chunks)`` must return a canonical list of chunk texts
    (deterministic order) for both paths.
    """
    grouped = _group_by_source(chunks)
    sources = sorted(grouped)
    rng = random.Random(seed)
    n_delete = max(1, int(len(sources) * deletion_fraction))
    deleted = set(rng.sample(sources, n_delete))

    survivors = [c for s in sources if s not in deleted for c in grouped[s]]
    incremental = rebuild_fn([c for c in chunks if _source_of(c) not in deleted])
    fresh = rebuild_fn(survivors)
    passed = _canonical(incremental) == _canonical(fresh)
    report = {
        "deletion_invariant_passed": passed,
        "deleted_sources": sorted(deleted),
        "surviving_chunks": len(survivors),
    }
    logger.info("Deletion invariant: %s", report)
    return report


def _source_of(chunk: Any) -> str:
    meta = getattr(chunk, "metadata", None)
    return meta.get("source", "unknown") if isinstance(meta, dict) else "unknown"


def _canonical(chunks: list[Any]) -> list[str]:
    return sorted(str(getattr(c, "page_content", c)) for c in chunks)
```

"""Draft generated by RAG Radar — untested, review before applying."""
from types import SimpleNamespace

from benchmark.deletion_check import deletion_invariant_report


def _chunk(text, source):
    return SimpleNamespace(page_content=text, metadata={"source": source})


def test_invariant_holds_for_deterministic_rebuild():
    chunks = [_chunk(f"chunk {i}", f"doc{i % 4}.pdf") for i in range(20)]

    def rebuild(cs):
        return sorted(cs, key=lambda c: (c.metadata["source"], c.page_content))

    report = deletion_invariant_report(chunks, rebuild, deletion_fraction=0.25, seed=1)
    assert report["deletion_invariant_passed"] is True
    assert report["surviving_chunks"] == 15


def test_invariant_fails_when_incremental_leaves_orphans():
    chunks = [_chunk(f"chunk {i}", f"doc{i % 4}.pdf") for i in range(20)]

    def rebuild(cs):
        # simulate a broken incremental path: keeps stale chunks
        if len(cs) < 20:
            return sorted(cs + [chunks[0]])
        return sorted(cs)

    report = deletion_invariant_report(chunks, rebuild, deletion_fraction=0.25, seed=1)
    assert report["deletion_invariant_passed"] is False
```

## Proposal: Enterprise_RAG_Blueprint

### Design
Close the partial gap: prove the loader's document deletion actually leaves an index equivalent to a fresh one, and surface deletion metrics. Purely additive test + one loader helper:

- `loader/deletion_check.py`: `rebuildable_index_check(sources)` — for a given set of document sources, compares (a) the chunk multiset in Chroma after `delete_document(source)` against (b) a freshly re-chunked + re-embedded build of the surviving sources' full content. Reuses `upload_documents_to_vectorstore` and the existing Chroma `where={"source": ...}` filter conventions (`loader/vector_store.py:84-85`).
- FastAPI route `POST /deletion-check` on `loader_api.py` returning the report, so an operator can verify index health after bulk deletions (complements the existing `DELETE /upload-jobs/{job_id}`).

#### NEW `loader/deletion_check.py`
```python
"""Draft generated by RAG Radar — untested, review before applying.

Deletion-invariant check for the Chroma vector store (Lightfoot-style):
after deleting a document's chunks, the remaining store content must be
equivalent to a fresh ingest of the surviving documents.
"""
import logging
from typing import Optional

from vector_store import (
    VECTORDB_DIR,
    INDEX_NAME,
    OLLAMA_BASE_URL,
    get_full_document_content_local,
    list_document_sources_local,
)

logger = logging.getLogger(__name__)


def _store_chunks(sources: list) -> list:
    from langchain_chroma import Chroma
    from langchain_ollama import OllamaEmbeddings

    embeddings = OllamaEmbeddings(base_url=OLLAMA_BASE_URL, model="nomic-embed-text")
    vectorstore = Chroma(
        collection_name=INDEX_NAME,
        embedding_function=embeddings,
        persist_directory=VECTORDB_DIR,
    )
    out = []
    for source in sources:
        where_filter = {"source": {"$eq": source}}
        data = vectorstore._collection.get(where=where_filter, include=["documents"])
        for doc in data.get("documents", []) or []:
            out.append(doc)
    return sorted(out)


def deletion_check(deleted_sources: list) -> dict:
    """Compare post-deletion store against the surviving documents' full content.

    Note: full re-embedding comparison is expensive; this checks that no
    chunk of a deleted source survives and reports the remaining index
    inventory (chunk counts per source) as the verifiable handle.
    """
    remaining_sources = [s for s in list_document_sources_local() if s not in set(deleted_sources)]
    leftover_deleted = [
        s for s in deleted_sources if get_full_document_content_local(s) is not None
    ]
    chunks_per_source = {s: len(_store_chunks([s])) for s in remaining_sources}
    report = {
        "deleted_sources": sorted(deleted_sources),
        "leftover_deleted_sources": leftover_deleted,
        "deletion_clean": len(leftover_deleted) == 0,
        "remaining_sources": len(remaining_sources),
        "chunks_per_source": chunks_per_source,
    }
    logger.info("Deletion check: %s", report)
    return report
```
