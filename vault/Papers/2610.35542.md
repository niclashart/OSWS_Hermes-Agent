# Hypergraph-Enhanced Evidence Selection for Long-Context Multimodal Document QA

**Axis:** [[New-Techniques]] · **Score:** 7/10 · [arXiv](https://arxiv.org/abs/2610.35542) · [PDF](https://github.com/niclashart/OSWS_Hermes-Agent/blob/main/papers/2610.35542/paper.pdf)

## Core idea
HyperDoc builds a document hypergraph over multimodal elements and does budget-aware hyperedge selection to pick evidence for a VLM.

## Results
> "HyperDoc constructs a document hypergraph to explicitly capture structural, logical, and cross-modal relationships among multimodal document elements. Over this structured evidence space, HyperDoc performs adaptive cost-aware hyperedge selection based on query intent and input budget." (Abstract)
