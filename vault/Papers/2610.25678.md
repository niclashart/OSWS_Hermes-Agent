# Cross-Pollination Retrieval (CPR-Dataset)

**Axis:** [[Datasets]] / [[Retrieval]] · **Score:** 7/10 · [arXiv](https://arxiv.org/abs/2610.25678) · [PDF](https://github.com/niclashart/OSWS_Hermes-Agent/blob/main/papers/2610.25678/paper.pdf)

## Core idea
Cross-field transferable-idea retrieval; CPR-eval (1,300 queries, 26 fields) + CPR-train (10,573 pairs); fine-tuned retriever transfers to AnaloBench and BRIGHT. Open data and code.

## Results
> "On CPR-eval, the best of eleven existing retrievers reaches a Recall@10 of only 0.26, whereas an LLM reranker reaches 0.81. Standard contrastive fine-tuning on CPR-train raises Recall@10 to as high as 0.70" (Abstract)
