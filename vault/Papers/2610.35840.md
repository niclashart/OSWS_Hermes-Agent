# ACARE: Agent-Context-Aware Reranker for Iterative Search

**Axis:** [[Reranking]] · **Score:** 7/10 · [arXiv](https://arxiv.org/abs/2610.35840) · [PDF](https://github.com/niclashart/OSWS_Hermes-Agent/blob/main/papers/2610.35840/paper.pdf)

## Core idea
Compact 4B reranker scores documents against the sub-query plus task/agent context; improves retrieval quality in agentic search with fewer searches. Code announced but not yet released.

## Results
> "Across multiple benchmarks and agent families, ACARe improves retrieval quality over its base reranker while reducing search effort." (Abstract)

## Relevance for RAG-NIMBF
The reranker itself could be a `matrix.reranker_models` value once weights ship, but its context-aware use presupposes an iterative agentic search loop that RAG-NIMBF cannot express; new axis candidate (agentic retrieval context).
