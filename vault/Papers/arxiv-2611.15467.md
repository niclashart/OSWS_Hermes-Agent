# AutoOntic: Automatic Ontology Induction from Text for Knowledge Graph Construction

**Axis:** [[New-Techniques]] · **Score:** 8/10 · [arxiv.org](https://arxiv.org/abs/2611.15467) · [GitHub](https://github.com/screemix/AutoOntic)

## Core idea
Automatically induces an ontology (type hierarchy, domain/range constraints) for graph-RAG from schema-free LLM extractions; 88% retrieval accuracy on MINE.

## Results
> "On MINE, knowledge graphs organized using an ontology built by AutoOntic achieve 88% retrieval accuracy." (Abstract)
