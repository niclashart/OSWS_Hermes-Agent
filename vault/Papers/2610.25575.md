# Structured RAG Benchmark in Perovskite Photovoltaics

**Axis:** [[Retrieval]] / [[Datasets]] · **Score:** 8/10 · [arXiv](https://arxiv.org/abs/2610.25575) · [PDF](https://github.com/niclashart/OSWS_Hermes-Agent/blob/main/papers/2610.25575/paper.pdf)

## Core idea
Quantitative QA benchmark (755 answers from 45,441 device records, verified ground truth) comparing six retrieval architectures vs read-only SQL execution, on an open 14B model on one 24 GB GPU.

## Results
> "standard passage retrieval tops out at 16-23% accuracy ... equipping the language model with read-only SQL execution over the structured device table elevates accuracy to 51.5% on historical and 50.8% on prospective literature -- a 33.01.8 percentage-point advantage over hybrid text retrieval" (Abstract)
