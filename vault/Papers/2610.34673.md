# Agent Memory as Recommendation: Recommender-System Design for Long-Term Memory of LLM Agents

**Axis:** [[New-Techniques]] · **Score:** 7/10 · [arXiv](https://arxiv.org/abs/2610.34673) · [PDF](https://github.com/niclashart/OSWS_Hermes-Agent/blob/main/papers/2610.34673/paper.pdf)

## Core idea
Agent memory selection as budgeted slate recommendation; AgentMemRec selects memories with zero LLM calls via candidate generation + LTR + slate construction.

## Results
> "On multi-session questions of LongMemEval, AgentMemRec outperforms memory and context-selection methods, including A-Mem, HippoRAG 2, DynamicRAG and T-Mem, by 10 to 31 points of accuracy." (Abstract / Results)
