# Memory Tax: Dissecting the Net Value of Agent Memory

**Axis:** [[Evaluation]] · **Score:** 7/10 · [arXiv](https://arxiv.org/abs/2610.34073) · [PDF](https://github.com/niclashart/OSWS_Hermes-Agent/blob/main/papers/2610.34073/paper.pdf)

## Core idea
Many dedicated memory systems underperform naive RAG over raw history; decomposes net value into memory benefit vs memory tax.

## Results
> "Through a large-scale evaluation across multiple benchmarks and model backbones, we find many dedicated memory systems underperform naive RAG in many cases, indicating a negative net value." (Abstract)
