# OpenSaC: Search as Code

**Axis:** [[New-Techniques]] · **Score:** 7/10 · [arXiv](https://arxiv.org/abs/2610.25779) · [PDF](https://github.com/niclashart/OSWS_Hermes-Agent/blob/main/papers/2610.25779/paper.pdf)

## Core idea
Agents write programs composing search, reading, reranking, and model calls (Search as Code) instead of tool-calling loops; open-source library + skill.

## Results
> "the OpenSaC configuration uses less execution time and fewer model tokens on BrowseComp and WideSearch, with higher accuracy on BrowseComp and slightly lower row F1 on WideSearch" (Abstract)
