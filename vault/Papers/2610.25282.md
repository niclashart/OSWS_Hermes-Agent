# MEMORA: Memory-Enhanced Committee Reranking Agent

**Axis:** [[New-Techniques]] / [[Reranking]] · **Score:** 7/10 · [arXiv](https://arxiv.org/abs/2610.25282) · [PDF](https://github.com/niclashart/OSWS_Hermes-Agent/blob/main/papers/2610.25282/paper.pdf)

## Core idea
Agentic committee reranking: query decomposition into intent factors, factor-specific evidence matrix, memory-conditioned meta-verdict, plus an episodic memory module and a CoT-fine-tuned dense retriever. Open code.

## Results
> "MEMORA achieves nDCG@10 of 41.5 (text-to-text) and 38.9 (multimodal query-to-text), outperforming the strongest agentic text-only baseline by +8.3 points and the strongest agentic multimodal baseline by +7.9 points" (Abstract)
