# Weaver: Personalized RAG via Incremental Reasoning (arxiv-2611.05900)

**Score:** 7/10 · [arXiv](https://arxiv.org/abs/2611.05900)

## Core idea
Personalized RAG framework that incrementally weaves memory-conditioned retrieval trajectories with compositional preference reasoning. Built on a Dual-Layer Retrieval and Reasoning Graph (Intent Dependency Graph over Memory-Conditioned Retrieval Trajectory Graph): it tracks remaining information gaps, retrieves missing evidence using established premises from past conversations, and resolves complementary/alternative/conflicting preference support scoped to temporal and situational context before answering.

## Key results
- > "Experiments on personalized RAG benchmarks, particularly PersonaMem, demonstrate that Weaver outperforms leading baselines in both evidence completeness and answer quality" (Abstract)
- Components: Dependency Information Gap Tracking, Memory-Conditioned Incremental Retrieval, Scope-Aware Compositional Reasoning (Sec. 3).
