# ArcRAG: Agentic Compositional Retrieval over Knowledge Graphs (arxiv-2611.06481)

**Score:** 8/10 · [arXiv](https://arxiv.org/abs/2611.06481)

## Core idea
GraphRAG retrieval strategies are usually co-designed with one graph construction pipeline. ArcRAG instead induces a query-local graph interface at inference time (node labels, relation descriptors, property keys reachable from the question's entities), plans multi-hop traversals against it, and executes and repairs them as Cypher. The same retriever configuration stays effective across a schema-guided graph and an open-IE graph of the same corpora (MuSiQue, HotpotQA, TriviaQA), demonstrating cross-construction portability.

## Key results
- > "query-time interface induction keeps a construction-agnostic retriever effective when the construction changes, although construction still shapes absolute accuracy" (Abstract / Sec. 6.2)
- > "we find that retrieval need not be co-designed with the graph" (Abstract)
- Evaluation against a construction-agnostic Direct-Cypher agent with per-stage ablations across retry and pass budgets (Sec. 5–6).
