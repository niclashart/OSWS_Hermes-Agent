# RAGCompass: Generalizable Retriever Routing via Reranking (arxiv-2611.05596)

**Score:** 8/10 · [arXiv](https://arxiv.org/abs/2611.05596)

## Core idea
Query-adaptive routing among multiple retrievers. Instead of routing on query-only features with a fixed retriever pool, RAGCompass reads the retrieved passage sets themselves, so passages from an unfamiliar retriever or corpus stay comparable. A contrastively fine-tuned reranker (against the answer each evidence set produces) plus a small comparison head selects the best retriever per query; neither component has retriever-specific parameters.

## Key results
- > "RAGCompass improves answer F1 by 28% relative to the best fixed retriever, and outperforms fusion baselines, three query-only routers, and a prompted 8B language model" (Abstract)
- > "RAGCompass keeps most of its gain under an unseen corpus, retriever, or reader, while query-only baselines fall to the best fixed retriever or below" (Abstract / generalization experiments)
- > "a contrastively fine-tuned reranker against the answer each evidence set produces ... accounts for most of the gain" (Abstract)
